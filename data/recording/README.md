# 三案录屏材料 1.0

三份 Word 分别对应顾舟劳动关系案、林澄工资争议案和乔安工资争议案。三个案例的当事人、相对方和核心事实互不复用，并与 `lexaegis.demo.SCENARIOS` 的 linkage、human_veto、success 一一对应。每份材料包含案件信息、事实概述、时间线、证据目录、材料摘录、任务范围、复核要点和导入登记，共 7 页。

首页“导入 Word 材料”将文件 SHA-256 与 `RECORDING_DOCUMENTS` 对照，加载对应的内置事实和补充资料；不按文件名决定结果，不预建任务、审批、风险通过或发送记录。修改文件后需重新审核并登记摘要。

第一案保留“唯一岗位、地点、公开获奖日期”的组合线索，用于触发现有边侧阻断标准。第二案在工资争议必要事实之外包含园区、夜班岗位和表彰日期，并在复核阶段引入对应公开资料，用于人工否决当前披露请求。第三案只保留工资摘要所需的劳动关系、合同日期、工资请求、金额及证据用途，完成主体替换、来源核对、人工法律复核和独立审批后可以执行当前请求。demo 环境不调用真实边侧或云端模型，不构成真实模型推理验收。

三份文件只提供输入事实和处理范围，不写入阻断、否决、批准或执行结果。上述结论均由导入后的系统流程和具名人工操作形成。
