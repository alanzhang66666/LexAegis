# 三案离线演示材料

此目录包含演示工作台识别所需的三份 Word、事实映射和内容清单。上传文件按正文 SHA-256 匹配，不按文件名决定案例；正文不匹配时会拒绝导入。

| 编号 | 文件 | 流程分支 |
| --- | --- | --- |
| LA-001 | `LA-001_终端销售劳动争议_完整版.docx` | 边侧风险判断阻止当前候选继续 |
| LA-002 | `LA-002_店长劳动关系确认_完整版.docx` | 进入具名人工复核，可否决当前请求 |
| LA-003 | `LA-003_平台配送劳动争议_完整版.docx` | 最小化后进入具名人工复核，可继续当前本地演示流程 |

Word 正文保留了用户提供材料中的原文部分，供本地原文查看和证据回链使用。该材料用于离线演示，不属于评测数据集，不是正式案件数据库，也不能用于真实外部处理。运行时导入件、案件记录、人工复核记录和账户设置仍写入被忽略的 `.data/`。

`manifest.json` 使用仓库内相对路径并登记材料 SHA-256。`scenarios.json` 提供与三份正文对应的本地事实和边界内容。修改材料或映射后，必须重新核验哈希及案例对应关系。
