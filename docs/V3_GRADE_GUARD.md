# V3 等级附加门禁（试点）

本切片是 PR #6 等级审批的增量实现，不是全部四项交付。生产正式云端任务可由当前法学复核人调用 `POST /api/v1/tasks/{id}/v3-grade-assessment`，对当前冻结请求登记等级。接口要求该账户仍为 active `legal_reviewer`、存在本人对同一请求和材料版本的 `allow_processing` 法学复核，且请求所属领域快照绑定的 `gate_profile` 已发布、当前有效、内容哈希与签名通过。签名规则包 `content.v3_grade_policy` 必须显式声明 `version: 1` 和非空 `permitted_grades`，该包使用现有 `LEX_PACKAGE_SIGNING_KEY` 验证，最低长度为 32 字节，密钥轮换会使既有等级记录失效。登记绑定请求、规则包、快照、复核记录、具名账户及最多 30 分钟有效期，并用现有包签名密钥计算独立域 HMAC，在审计中留痕；规则/账户/材料/请求变更会使检查失败。列表/详情读取时重新投影等级状态，避免已经撤销时仍显示旧的可批准状态。

等级判断由具名法学复核人作出；系统只阻止与既有确定性风险状态冲突的降级，不把模型或哈希当法律意见。L1/L2 可进入既有流程，但仍须通过全部现有 G0–G10、现有具名审批、一次性许可和网关；L4/UNKNOWN 拒绝。L0 暂缺公开内容证明，L3 暂缺组织级 partner/DPO 双角色身份授权，均保持阻断，不把通用账户角色冒充这两种真实资质。当前不是按 PR #6 最终交互次数完成的审批体系。

`LEX_V3_GRADE_GUARD=1` 时，生产正式云端任务缺少有效等级即在审批、排队和 worker 领取发送前拒绝；不设置或 `0` 保持旧任务行为。一个任务一旦登记等级，即使开关关闭也继续执行该附加检查；错误开关值失败关闭。正式发送现有门禁未放宽。接口需要当前请求哈希和等级；未提供 ID 时由服务端根据任务快照和本人当前法学复核确定唯一 profile 和复核记录，也可显式提供 ID。法学复核人可从风险工作台登记等级；登记后自动请求一次正式门禁检查。无已签有效 profile 时无法登记。

本地 HMAC 是现有包签名技术机制，不证明真实律师资格、组织授权或法律正确性。检查在 worker 领取前执行，尚未完成网关侧独立信任锚和领取后的实时撤销传播，因此不能声称 PR #6 权威证明复用、完整撤销或生产验收完成。能力状态计算、A/B 独立网关/账本及真实云、目标环境与法学安全验收仍待实现和实测。部署时 API 和 worker 的配置及密钥必须一致并另行安全审查；本变更未启用任何生产开关或接入真实案件。
