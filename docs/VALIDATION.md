## 已实现但仍需目标环境验证

- 边侧 OpenAI-compatible 提取契约已实现并通过异常响应测试；尚未连接真实 Ollama/llama.cpp 模型，因此没有真实推理质量结论。
- PaddleOCR 3.x 本地适配器、坐标和失败关闭路径已测试；尚未安装真实引擎及权重，因此没有 OCR 精度或硬件兼容性结论。
- 云端网关及 OpenAI-compatible 适配器已用测试替身验证；未配置真实服务商或 API 密钥，也未发生真实云端外发。
- GitHub Actions 已定义 Windows、macOS、Linux、浏览器五视口以及 `linux/amd64`、`linux/arm64` 镜像检查；本记录不把尚未取得的远端运行结果写成已通过。
- Dockerfile、Compose 隔离拓扑和失败关闭自检已实现；当前机器没有 Docker，尚未取得容器构建及真实网络隔离运行证据。

以上项目是外部运行环境验证缺口，不是以模拟结果代替真实结果。系统继续把未取得验证证据的能力显示为“未验证”或“阻断”。

## 当前合成数据范围

`lexaegis dataset generate-mock` 生成 8 份完全合成的劳动争议记录，固定为 6:2 开发/盲测划分。`freeze` 冻结数据、模板、依赖和随机种子哈希；`run` 生成原文、查找替换、一致假名化、任务驱动最小披露四组文本对照，以及独立的 Ianvs 向量补充组。

这些数据不来自真实案件，只验证管线可复现性。法律可用性、人工耗时、正式四类攻击效果和 MIA 效果均明确记为 `not_applicable` 或待标注，不生成伪造分数。
