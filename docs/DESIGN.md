# 案隐盾界面设计基线

本文件是 LexAegis 的原创设计规范。参考 `HU-UH/awesome-design-md` 中对 Notion、Linear、Stripe 等产品的非官方设计观察，但不复制品牌标识、专用字体、插画、营销文案或组件代码，也不加载 CDN 与远程字体。

## 信息原则

界面分别展示五种事实：技术是否实现、运行能力是否配置、法学规则是否发布、攻击协议是否完成、当前案件是否通过。不得用单一绿色状态或综合百分比表达“安全”或“合规”。阻断必须写明原因；未知、错误、未运行和不适用都不能显示为通过。

工作台采用 `AppShell → 案件列表 / 案件工作台 / LegalPackCenter / ProviderCenter / BenchmarkCenter / 运行配置`。案件工作台内保持原文、操作区、依据栏的逻辑分区；复原页逐条并列展示云端句、本地句、披露支持、原文锚点和问题。

## 视觉 Token

- 8px 间距系统；控件 6px 圆角，面板 8px 圆角。
- 暖中性画布与纸张表面，案隐盾绿色为操作主色。
- `info / success / warning / danger` 独立语义色；状态同时使用文字、圆点或图标。
- 中文使用系统字体栈；金额、版本和哈希使用系统等宽字体。
- 阴影仅用于浮层；常规信息层级优先依靠间距、边框和字体。

## 可访问性与响应式

- 所有操作可键盘到达，使用清晰 `:focus-visible`，正文与控件满足 WCAG AA 对比度。
- 尊重 `prefers-reduced-motion`；动态图标不承担唯一状态含义。
- 大于 1200px 为三栏；900–1200px 将依据栏变为抽屉；650–900px 原文与工作区用页签；小于 650px 为单栏，审批仍显示完整请求摘要。
- Playwright 视觉基线使用 1440、1280、900、650、390 像素。
