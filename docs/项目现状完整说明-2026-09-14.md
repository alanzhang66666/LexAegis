## 1. 一句话与硬口径

案隐盾是本地优先的法律材料披露工作台：原文、身份映射、锚点留在边侧；律师对**一次完整冻结请求**（提示词、facts、模型、地址、账号快照）具名批准后，独立网关才可调用云端大模型 API；回包在边侧校核、回链。

同时成立的否定句：

- 分词 `[[LEX:P0001]]` **不是**匿名，也不是去标识。
- 律师批准是发送控制，**不是**《个人信息保护法》第 13 条处理依据。
- 演示模拟发送是拼接已披露事实，**不是**模型生成。
- Compose 五项探测为真 **不是** 本请求隔离收据。`native` 启动 **不能** 自证隔离。
- 隔离栈工程基线攻击 **不是** 法学 `resisted`。
- 公开 TOS / 口述「确定不训练」**不是** 服务商档案 `reviewed`。
- 填十门空表 **不是** `pass`，**不是** 可发送。
- 不要写：「V1.0 已正式发行」「外发已开通」「10 案已通过」「已经匿名化」「CI 绿了」。

下一步（法学）：十门真收据齐了，才能对 **一次** 哈希绑定的 D 发送谈批准。一案成功不扩到另外九案。

## 2. 产品做什么、不做什么

### 做

1. 解析本机材料（DOCX、文本/扫描 PDF、图片、表格、可选本机 OCR/转写），块级复核后才能抽取。
2. 边侧（可选）只做正式案事实抽取；演示不调边侧。
3. 律师逐项决定披露：删、保留、变换；硬性禁止不能被界面绕过。
4. 风险检验冻结完整请求，生成 `request_hash`；正式案失败关闭。
5. 独立网关按白名单主机调用云端；流式只在网关拼 JSON；密钥不进 API/worker。
6. 回包按 `source_ids` 回链；默认导出 `cloud_view`（无真名/锚点）。含身份的本地复原包须二次具名确认。

### 不做 / 尚未被允许做

- 不把 mapping、原文、`anchors`、`local_text` 送上云。
- 正式案件不使用模拟调用（`mock` 仅演示）。
- 不在请求已离开本地或已有 token 后自动换备用服务商、不盲重发。超时或半响应记 `unknown`。
- 不代删服务商侧日志/缓存/备份。本地删除 ≠ 对方已删。
- 不把争点提取当成法律关系认定（只是六类字段分桶）。
- 仓库不分发模型权重、真实案件或效果数字（准确率、隐私降低率等一律未评分）。

## 3. 它怎么跑起来（结构）

三个本机进程：`lexaegis start` 拉起 API（工作台 **http://127.0.0.1:8765**，不要用 `localhost`）、worker、网关（**8766**）。口令看终端。`Ctrl+C` 停三个服务。

```
浏览器工作台 → API(8765) → 本地 SQLite(.data/app)
                         → worker → 边侧抽取(8080，可选)
                                  → 网关(8766) → 云端 chat/completions（仅批准后）
```

| 层 | 实现 |
| --- | --- |
| 后端 | Python 3.12+（本机曾用 3.13.2）/ FastAPI / SQLAlchemy，包 `lexaegis/` |
| 前端 | React + Vite，`frontend/`。三色系（林绿 / 墨青 / 缃褐）× 浅/深 |
| 存储 | 单实例 SQLite WAL，不可放网络盘。聚合表 `records(id, kind, scope, body)` |
| 角色 | `admin` / `case_operator` / `legal_reviewer` / `approver`。写操作校 Origin/Host |
| 隔离栈 | Docker Compose：api / worker / gateway，另有 edge / redteam / benchmark。宿主机默认 **38765**（避开 native 8765）。先停 native |
| 正式任务状态 | `draft → review/blocked → approved → queued → sending → complete/unknown/failed` |

工作台五个表面：登录与案件；四步（事实 → 披露方案 → 风险冻结/审批 → 摘要回链）；治理四页（法学规则、服务商、隔离实验、本地用户）；运行配置（边侧 URL、主备回显，密钥不进此页）；共享 UI。

核心模块：`api.py` 会话与 HTTP；`service.py` 案件/评估/批准/入队；`policy.py` 风险与标识；`governance.py` 服务商检查与 `validate_formal_gate`；`d_path.py` D 试点（单主槽、九案层 B 关闭、准标识）；`cloud.py` / `gateway.py` 双槽与白名单；`worker.py` 队列；`disclosure.py` 加班核对草稿。

## 9. 本机如何复现（合成演示）

需要 Python 3.12+。从源码编前端需要 Node.js 22+、pnpm 11（本机可能更高）。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
cd frontend
pnpm install --frozen-lockfile
pnpm build
cd ..
python scripts/make_examples.py
lexaegis start
```

打开 **http://127.0.0.1:8765**，口令看终端。不配云、不下边侧，即可走演示 01：披露方案 → 检验风险 → 批准 → 模拟调用 → 回链。02 不要强行批准。正式案上传合成材料应 **409**。
