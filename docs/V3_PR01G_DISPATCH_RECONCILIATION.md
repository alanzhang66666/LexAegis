# V3 已领取发送与网关核对

生产正式云端请求在 worker 调用网关前已经持久化领取一次性许可。此后出现连接异常、超时或 HTTP 错误时，任务进入 `unknown`，许可和一次性策略保持消费；后续只允许查询网关，不自动重发，也不把连接异常解释为未披露证明。发送前本地门禁拒绝仍沿用原有的许可撤销逻辑。

非正式发送在没有正式许可且明确出现 `httpx.ConnectError` 时，可从 `sending` 返回 `queued`，作业进入 `waiting-cloud` 延迟队列；普通 `OSError`、通用连接错误和读超时不证明未发送，归为不明状态。重启时，生产正式任务只有在任务仍排队、许可仍为 `reserved`、策略未消费且没有领取记录时才重新排队；状态不一致按不明处理，不能自动重发。

`unknown` 状态可人工发起只读网关查询，重复提交复用已有待处理/运行中的查询。查询 HTTP 错误、响应与当前请求 ID 或哈希不符、状态不合法，均保持 `unknown`；不推断之前未发送。已结束或请求已变化时，迟到查询及重启时的过期查询取消，不覆盖终态。

这些保护只在本地代码和合成网关/provider 夹具中验证；不是对真实目标网络、服务商记录或法律批准的证明。跨案件证明复用及部署验收仍另行完成。
