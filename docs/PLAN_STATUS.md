## 不应被误报为工程完成的事项

下列事项需要法学参与，按当前约定暂缓：

- 正式案由的法源、适用日期、任务必要性、禁止项、风险权重及发布签署。
- 服务商法律角色、合同、影响评估、跨境/地区处理条件和允许范围审核。
- 四类攻击的正式攻击者知识、辅助数据、阈值、成功标准及接受结论。
- 双人法律标注、第三人仲裁、法律任务可用性评价和正式试点授权。

下列事项需要外部运行资源，不能仅靠当前仓库声明完成：

- GitHub Actions 在 Windows、macOS、Linux 与双架构镜像上的实际远端结果。
- 有 Docker 的主机上验证 API/worker 无公网、gateway 无案件卷、redteam/benchmark 无正式数据。
- 真实 Ollama/llama.cpp、PaddleOCR 权重和经审核云端服务商的兼容、性能与稳定性验证。

在以上证据补齐之前，`/capabilities` 和正式门禁继续区分“技术实现”“运行配置”“实际验证”“法学发布”，不会把单一绿色状态解释为安全或合规。
