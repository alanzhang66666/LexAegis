# V3 L3 双人角色记录（尚不授权外发）

在已启用的 V3 等级门禁和当前、有效的 L3 法学等级记录之上，系统可以记录两个组织角色动作。发布的签名 gate profile 的 `v3_grade_policy.l3_role_holders` 必须恰好包含 `legal_partner` 和 `data_protection_officer` 两个非空名单；每项为 `user_id` 与 `authority_hash`。两组账户不得重叠。前者须以对应的活跃 `legal_reviewer` 会话操作，后者须以对应的活跃 `approver` 会话操作；服务端使用会话身份，不接受客户端冒充角色或账户。

每条 HMAC 记录绑定当前请求、等级记录、规则包哈希、账户状态和期限；读取时重新核验。更改请求、停用账户、撤销或篡改规则包、变更等级或签名密钥后，旧记录不再有效。并发重复操作保持幂等。摘要只是机构依据的引用，不证明底层文件、本人身份或专业资质已经核验。

两个动作齐备也不解除 L3 禁发：真实法域准入、PIA/CTIA 证据验证、旧 G0-G10 门禁和一次性许可仍需实现或逐项满足。本功能不提供权威证明复用、A 链独立传输、不实现真实云调用，不构成法律或安全验收。生产环境的 V3 等级门禁默认关闭，须显式设置 `LEX_V3_GRADE_GUARD=1`；曾登记等级的请求继续受门禁约束。使用前须安全配置签名密钥与签名规则包，不要把测试账户或占位摘要当成正式依据。
