# V3 PR-01 契约基础（本地可验证，不授予外发权限）

本切片对照 [PR #6 V3 交付矩阵](https://github.com/alanzhang66666/LexAegis/blob/9141c6b07104e1604aad923d8e1fde5d462a1d54/docs/V3_0_DELIVERY_MATRIX.md)：新增版本化、拒绝未知字段的规划数据模型、只读 V2 适配器和可重算指纹。旧的 `contracts.py`、生产 API、网关、`formal_release`、任务状态机和现有 V2 wire 数据没有改动。

- `contracts_v3.py` 含隐私评估、候选执行计划、链路意图、链路决定、实验释放收据、网关收据、事实引用、外发能力候选和请求范围候选。实例是未认证数据：`verified=false`、`approval_granted=false` 和 `authorization=false` 均不能替代真实门禁、法学签署或网关验证。`available` 仅是具有三类不同引用的未验证候选，不表示实际可发。
- 上下文快照只接收调用方提供的摘要/引用，不接收原文或映射；摘要是关联标识，不是匿名化证明。V2 快照适配包括完整旧快照指纹，若缺整包哈希则标注引用的是 `cause_pack`。V2 请求级策略适配须绑定相同请求；首案策略须由调用者显式提供当前请求哈希。适配器均不签发许可、不持久化状态、不改变旧策略。
- 冻结计划将任务、分类/政策版本、法源、服务商、接收方、风险评估和链路意图绑定进指纹；更改任一项改变或使关联失效。未知等级/敏感度/不确定状态与硬禁项不能生成 B 链云端候选；A 链不复用 B 路由；DP 路由仅能标识实验。该检查不是权威授权或生产风控，L 等级仍需法学规则审核。
- 两个合成黄金样本固定旧规范序列化字节和请求哈希；其中一个由现有首案正式请求测试夹具生成并对比。测试覆盖严格类型、未知字段、原文/映射字段拒绝、版本/来源/接收方变化、链路混用、计划不得自授批准和旧格式回归。

## 尚未完成

本切片尚未实现 PR-01 全部数据迁移及 API 接入，也未完成 PR-01b 权威分层证明复用、L0–L4 正式路由及角色审批、按证明计算的外发能力、A/B 独立真实发送、真实云回执、目标环境和法学验收。现有正式外发状态不变；不要将本模块中的字段值当作可发送证明。
