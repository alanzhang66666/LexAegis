# V3 回流金额一致性与采纳前重验

## 已接入的行为

`output_checks` 新增默认 block 的 `unsupported_amount` 检查，进入现有九阶段返回管道。每条返回陈述只与它引用的、实际已披露的 fact decision output 对照；不能用无关事实、已删除字段或仅存在于本地原文的值为云端新增内容辩护。

金额比较采用 Decimal，区分数值、正负号和单位，支持常见千分位、全角数字以及千/万/亿的单一倍率。默认阻断例如 `9800元→800元`、`5000元→5万元`、`9800元→9800美元`。它不再把数字子串出现当成金额相等。币种不换算，裸“元”不推断为 CNY；货币符号和明确币种也不擅自互相等同。未覆盖的科学记数、空格分组、畸形逗号等不得贡献局部数字来支持错误金额。

每条候选保存服务端生成的 `amount_support`：校核版本、已披露引用内容摘要、识别金额与原文坐标、匹配的 fact IDs、缺乏支持的金额。报告始终 `semantic_entailment_verified=false`。金额相同不证明工资/奖金、已付/应付、主体、期间或反证关系相同。

## 人工动作与旧数据

单条复核及最终 `/confirm` 在写入新的人工决定前均重验持久候选，因此升级前保存且已经逐条勾选的待采纳结果也不能跳过新增硬阻断。最终确认同时检查 hard blocker，不再只看 `reviewed=true`。合法的既有人工作出的 review 级决定保留，新增 block 级结果仍优先。

重验不重写历史 HumanDecision，不反向宣称既有文书已经更正；历史问题的复审另行处理。拒绝动作遵循现有事务回滚语义，不伪造采纳或外发记录。返回校核不产生发送权限。

另修复 fact 与 decision output 按列表 zip 可能错位的问题，改为按同一 fact ID 配对；被删掉输出的前一条事实不能借用后一条的立场或输出。

## 边界

此切片是确定性数值一致性，不是完整实质证据推理。中文大写金额、复杂表达、总额推算、原文是否支持整个主张、工资/奖金关系、主体/期间和正反证冲突仍须独立核验。`no_amount_tokens_checked` 仅表示未识别到本校核覆盖的金额，不是通过证明。

等价金额换写在本检查可识别，但不会删除既有数字、日期、语义或人工复核门禁产生的问题；本切片不保证这些换写均可直接采纳。规则包仍可显式配置 block/review/off，该配置不等于法律结论，报告即使关闭阻断仍显示。没有将任何仓库草稿包发布或调整为允许外发。

测试只使用仓库合成案件，覆盖 worker 返回管道、有效锚点但金额/币种被改、逐条复核、旧候选最终确认拒绝，以及现有正确工作流回归。没有真实云调用、真实案件或法律签署验收。权威证明复用、A/B 双链和完整 V3 仍按差距清单另行推进。
