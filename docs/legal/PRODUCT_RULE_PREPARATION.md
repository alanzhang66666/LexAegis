# 劳动争议产品规则草稿资料准备说明

本资料集为劳动争议常规业务范围准备的**独立 V2 规则草稿**，文件为 `packs/labor_product_draft.json`，配套导入报告为 `docs/legal/reports/labor_product_import_report.json`。它沿用现有 V2 草稿的任务、字段约束、披露规则、风险协议和其他声明式规则，沿用现有 `labor` 领域标识并使用独立版本号 `3.0.0-product-draft.1`，避免覆盖 `labor_v2_draft.json`。草稿不把适用案件固定为单一试点案，也不包含已发布范围。

草稿和导入报告均标记为待审核；`status` 为 `draft`，`legal_status` 为 `pending_legal_review`，`dispatch_allowed` 为 `false`，`published_scope` 为空。经 schema 和 runtime-pack request 导入验证，只表示格式、引用关系和受限草稿导入流程可用，不表示业务规则正确、法律适用已确认、法学审核已完成或可向外发送。

本稿将个人信息保护法第56条和第59条作为条文级草稿引用，并附工信部政策法规司官方页面：[《中华人民共和国个人信息保护法》](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)。第56条内容按“在依法触发影响评估时核对评估事项和至少三年记录保存”表达；是否触发须结合第55条及具体处理活动另行判断。第59条仅在实际受托处理关系成立时适用；各方角色、合同安排、安全措施和协助履责情况均需法学人员核实。本稿不依据服务商名称推定其法律角色。

## 资料整理与法学签署

资料整理工作包括：保留原草稿字段及规则结构；对新增法源补入条文、官方来源链接和待核验语境；增加影响评估触发/内容、委托处理角色/义务及旧引文处理的阻断式人工复核条件；以 V2 schema 和 runtime-pack request 流程进行结构验证。导入报告记录的是这一资料准备和技术校验状态。

法学签署仍须由有权法学审核人员完成。审核应核对全量规则与引文的现行效力、事实前提、任务适用范围、个人信息处理角色、具体委托关系、影响评估触发与履行证据、风险处置及各条款之间的冲突，并依系统的正式流程记录具名审核及对应证据。资料整理者不代填审核人、不签署法学结论，也不将 `draft_reference` 转为 `published`。

旧草稿中有关“律师法 2026 年修订文本/第41条”的说法在本稿中未采用，也不作为新事实或放行依据。遗留的律师法旧引文已标记为待核验；若业务确需引用，应由法学人员从权威公布文本核实版本、施行时间和准确条号后再修订。其余继承的草稿法源及规则同样尚未因本次结构检查而获得法律确认。
