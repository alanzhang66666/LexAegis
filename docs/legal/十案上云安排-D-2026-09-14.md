## R / W / I 必要性（草稿，旧批准不继承）

输出一律为待核稿，不得自动写成「法院已认定」。子目的必须显式传入，不因正文出现工资/工伤自动切换。

### R 劳动关系经过与争议状态（LA-001、LA-003、LA-004）

| 字段 | 进卡 | 精度 / 处理 |
| --- | --- | --- |
| entity / relation / event / claim_stance | 可，主体 token | 多主体不合并；主张与认定分开 |
| date | 条件 | 保留任务必要精度；冲突并列 |
| amount | 默认不进 | 本子目的不核金额 |
| evidence | 条件 | 名称与提及状态；证人/录音只本地 |
| 案号、公开链接、法院/地域、参考摘要 | 禁止进卡 | 字段政策：不要写入 wire。运行不再因文中出现链接而单独加准标识；案号仍拦。组合未判则整卡不放行 |

### W 欠薪、解除与经济补偿经过（LA-005，首版）

| 字段 | 进卡 | 精度 / 处理 |
| --- | --- | --- |
| relation / event / claim_stance | 可，主体 token | 概述争议、双方理由、二审维持；不算金额、不判期限 |
| amount | 禁止 | 首版不算金额 |
| date 中的待岗年份倒置 | 只本地 | 标冲突，不让模型猜改，不上云 |
| 案号、地域、职务、参考摘要、公开链接 | 禁止进卡 | 字段政策，不是「必须先有正式 URL 才能评估」 |

### I 工伤待遇争议经过（SMP-001–005）

| 字段 | 进卡 | 精度 / 处理 |
| --- | --- | --- |
| relation / 责任与待遇阶段 | 低精度可评估 | 关系与责任分开；金额本地核 |
| 病历全文、精细诊断、住院病案 | 默认禁止 | SMP-004/005 删减后任务做不完则 `local_only` |
| 数据库副本（如法宝 DOC） | 未知待审 | 未核订阅条款不得当已获准来源 |
