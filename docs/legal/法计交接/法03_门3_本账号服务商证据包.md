# 法 03 · 门 3 · 本账号服务商证据包及档案复核

负责：法学方对接实际 API 账号、向外取证；材料齐备后由承担 `legal_reviewer` 的人标 `reviewed`。公开 TOS / 隐私政策只能作对照，不能当本账号证。口述「确定不会用于」无效。管理账号 ≠ 处理条件已证。

询证不要附裁判文书、事实卡或 API Key。

缺**合同引用**、**签约主体全称**或**本账号训练与删除书面证据**时，不得标 `reviewed`，也不得发送。`unknown` 或空引用不得已审核。标 `reviewed` ≠ 可发送。

建议合并为一份「本账号服务商证据包」。
